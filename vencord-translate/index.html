Vencord Translate: how it works, fixes, and auto translation

Updated 2026-11-02

How Vencord's Translate button works, why it may not translate, how to change its language, and what to use when you want every incoming message translated.

What Vencord Translate does

Vencord is an open source modification for the Discord desktop app, and Translate is one of the features that ship with it. Once it is switched on, it adds a few things to Discord:

  • A Translate button that appears when you hover a message.
  • A Translate item in the menu when you right-click a message.
  • A translate icon in the chat bar, next to where you type, for its settings.

Press Translate on a message and the translation appears under it. Each message is one press.

By default it uses Google Translate. You can switch to DeepL or Kagi Translate, but each of those asks for your own key or session token from that company.

The "auto translate" setting is for your own messages

Many people switch on Vencord's Auto-Translate expecting incoming messages to translate by themselves. That is not what it does. Its own description reads: automatically translate your messages before sending.

So with Auto-Translate on, what you type is rewritten into another language before Discord sends it. Messages from other people still need a press of Translate, one at a time. You can also toggle this mode with Shift and a click, or a right-click, on the translate icon in the chat bar, which is a common way to switch it on by accident.

Fixes for common problems

Translate does not appear at all

Translate is off until you switch it on. In Vencord's settings, search for Translate, switch it on, and restart Discord if Vencord asks you to.

Translations come out in the wrong language

Click the translate icon in the chat bar to open its window. There are two pairs of languages: one for messages you receive, and one for messages you send. Set the "translated to" language for received messages to the language you read.

DeepL or Kagi gives nothing

Both need credentials from the service: a DeepL API key, or a Kagi session token. Paste it into the Translate settings. When you switch service, the language choices reset to their defaults, so check them again afterwards.

In the browser, there is no choice of service

On the web version of Vencord, the service setting is hidden and translations use Google.

When one press per message is too slow

Translate on request suits a chat where you meet a foreign line now and then. It gets tiring in a server where most lines are in a language you do not read: you end up pressing Translate on every message, and new ones arrive while you do it.

That is the gap Subline fills. Subline is also built on Vencord, and it is open source under the same GPL licence. The difference is what it translates and when:

  • Every incoming message, by itself. In server channels, each message in another language gets a translation under it as it arrives. No button.
  • Only what needs it. Messages already in your language, laughter, emoji and links get no line.
  • Context-aware AI. Each translation sees a few earlier lines of the chat, so replies, slang and typos read the way they were meant, rather than word by word.
  • No key to manage. You link your Discord account once.
  • Your messages are left alone. Subline never rewrites what you send.

Direct messages stay untranslated until you switch one on with the 🌐 button.

If you already use Vencord

Subline comes with its own build of Vencord. If Vencord is already installed in your Discord, the Subline app shows "Another mod is installed" and stops there. It puts Subline in Vencord's place only if you choose Replace it and continue. Think about which Vencord features you rely on before you do.

You can also keep your current setup and use Subline only in Chrome, on discord.com, where it does not touch the Discord app at all.

Same rules as any client mod

Vencord and everything built on it are client mods, and Discord's terms do not allow modifying the app. Vencord's own README says this openly, and that there are no known bans for using mods that do nothing abusive. The safety page covers how Subline handles that, and what it never does.
