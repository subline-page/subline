How to translate Discord messages automatically

You're in a server, the chat is moving fast, and half of it is in a language you don't read. Discord has no translate button. Here is every way to fix that, and the one that makes it feel like you've always spoken the language.

Translation bots

A server admin adds a bot like Translator or Talksy. You react with a flag, and the bot posts the translation as a new message.

It works, if the admin added it, in that one server, and if you don't mind every translation filling the chat for everyone.

Right-click apps

Apps like iTranslator work in any server: right-click a message, choose Apps, then Translate.

Fine for one message. In a fast chat, you're right-clicking forever.

Browser extensions

Extensions like Mate translate on discord.com.

Only in the browser. The Discord app you actually use stays untranslated.

Discord mods (Vencord, Equicord)

Vencord adds a Translate button to each message. Equicord can translate automatically with Google.

You install and set up the mod yourself, and it's raw Google: slang, typos and Hinglish come out wrong.
