How Subline keeps you safe

Updated 2026-11-02

What Subline does on your computer, what it sends, what it never does, how to check the downloads yourself, and an honest word on Discord's terms.

What Subline does

Subline shows a translation under each message in Discord, in your language. It reads the chat you already have open and writes the translated line below the original, on your screen only. Nobody else in the server sees it, and nothing is posted.

What it never does

  • It never sends a message, a reply or a reaction for you.
  • It never joins servers or automates anything in your chats.
  • It never changes what you type. Your own messages go out exactly as you wrote them.
  • It never reads your Discord password or the email address on your Discord account.

The only requests Subline makes to Discord are for the sign-in that links your account. The first time, you approve it in Discord's own Authorize window. On another computer, Subline reuses that approval without showing the window again, and only if Discord says this account already approved it. Subline asks only for the basic identify permission. It cannot post as you.

What leaves your computer

To translate a message, Subline sends its text to Subline's own server, which asks an AI service for the translation. A little of the chat around it goes too, so slang and replies make sense.

  • Subline's server does not store the messages it translates. For a ⚡ translation without AI, it keeps only a scrambled form of the text for up to 3 days, so the same message is not counted twice.
  • The AI service never sees your IP address, your Subline code or your install id.
  • Direct messages are off until you turn one on, one conversation at a time.
  • A report about a bad translation goes only when you press Send, and you see all of it first.

Everything is listed, with how long each thing is kept, on the privacy page.

The source code is public

The part of Subline that runs inside Discord is open source under the GPL. Every release is published with its own tag in its public repository on GitHub, so anyone can read exactly what runs, or build it themselves.

Check the downloads yourself

We uploaded each Subline 0.2.9 download to VirusTotal, which scans a file with dozens of antivirus engines. None of them flagged anything:

  • Windows installer: 0 of 68 engines
  • Mac, Apple silicon: 0 of 61 engines
  • Mac, Intel: 0 of 37 engines

Each link opens the report for the exact file, named by its SHA-256 fingerprint. The same fingerprints are in the SHA256SUMS file of every release on GitHub, so you can match the file you downloaded.

On a Mac, the app is signed by its developer and notarized by Apple, which means Apple's automated check scanned it for malicious software.

On Windows, the app is not signed yet. If your browser asks, choose Keep. The first time it runs, Windows warns about an unknown publisher: choose More info, then Run anyway. The scans above are for that exact installer.

What it changes on your computer

The Subline app adds Subline to the Discord app. It keeps Discord's original files next to the change, so Discord can be put back exactly as it was.

A small helper checks every 5 minutes that Subline is still in place after a Discord update, and repairs it if needed. On a Mac it is a login item; on Windows it is a scheduled task that runs as you, with the lowest rights. It never closes Discord by itself: when a repair needs a restart, it asks you.

To remove Subline, open the Subline app and choose Uninstall. Discord is restored and the helper is removed. On Windows you can also uninstall from Settings, then Apps.

The Chrome add-on

The add-on works only on discord.com in your browser. It does not touch the Discord app on your computer. It can reach two places: Discord's own pages and Subline's server. It needs no other permission.

Discord's terms, honestly

Subline is built on Vencord, a well known open source modification for Discord. Discord's terms of service do not allow software that modifies Discord, and that includes client mods like Vencord and everything built on it. We would rather you hear that from us.

Vencord's own documentation says that Discord is largely indifferent to client mods and that there are no known cases of users being banned for using them, as long as nothing abusive is added. Subline is built to stay on the quiet side of that line: it only reads the chat and shows a translation. It never sends anything, never automates anything in your chats, and never acts for you.

The Chrome add-on runs the same code inside Discord's web page, so the same terms apply there. If your Discord account matters so much that any risk is too much, Vencord's own advice is not to use any client mod at all, and we agree with it.

Questions

Can people in the server tell that I use Subline?

No. The translations exist only on your screen. Nothing is posted, and Subline never acts in the chat.
