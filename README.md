# Subline

Read Discord in your language. Subline puts a translation under every message you can't read, inside the Discord desktop app you already use.

- ≈ Google translation on every message: $4.99, once.
- ✦ Context-based AI translation: $1.99 a month, or $19.99 a year.

**Download:** [subline.page](https://subline.page) (Mac and Windows). This repository holds the releases and the website.

**Privacy:** [subline.page/privacy](https://subline.page/privacy/)

**Source:** the plugin's source code (GPL-3.0) is at [subline-page/vctranslate](https://github.com/subline-page/vctranslate), one tag per release.

**Support:** support@subline.page

Not made by Discord.
