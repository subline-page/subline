디스코드 번역: 모든 메시지를 내 언어로, 봇 없이

업데이트 2026-11-20

디스코드를 자동으로 번역하는 방법. 복사 붙여넣기, 봇, Vencord, Subline을 비교합니다. Subline은 각 메시지 바로 아래에 나만 보는 번역을 보여 줍니다.

다른 언어를 쓰는 서버에 들어갔을 때

게임, 스터디, 해외 커뮤니티 서버에 들어가면 채팅의 절반이 영어나 일본어, 스페인어, 포르투갈어로 흘러갑니다. 채팅은 빠르고, 읽다 보면 어느새 대화에서 밀려납니다. 디스코드 번역 방법을 검색하면 서로 전혀 다른 방식이 여러 개 나옵니다. 무언가를 설치하기 전에 각각 어떻게 다른지 알아 두면 좋습니다.

디스코드를 번역하는 네 가지 방법

  1. 복사해서 붙여넣기. 메시지를 복사해 번역 사이트에 붙여넣고, 읽은 뒤 돌아옵니다. 한 문장이면 괜찮지만, 몇 초마다 새 글이 올라오는 채널에서는 금방 뒤처집니다.
  2. 번역 봇. 서버 관리자가 봇을 추가합니다. 국기 이모지로 반응하거나 명령어를 입력하면 봇이 번역본을 채널에 올립니다. 관리자가 설치한 서버에서만 쓸 수 있고, 모두의 채팅에 번역본이 쌓입니다.
  3. Vencord의 Translate 기능. Vencord는 디스코드용 오픈소스 모드입니다. Translate 기능은 메시지를 클릭하면 Google 번역으로 옮겨 줍니다. 유용하지만 수동이라서, 메시지마다 한 번씩 눌러야 합니다.
  4. Subline. 메시지가 도착하자마자 자동으로 번역해, 바로 아래에 내 언어로 보여 줍니다. 클릭도 봇도 필요 없고, 나만 볼 수 있습니다.

실제 채팅에서는 이렇게 보입니다

국제 서버에서는 이런 대화가 오갑니다.

  • sam: anyone up for ranked tonight?
  • lucia: yo me apunto, a las 9?
  • jiwoo: 저는 10시 이후에 가능해요

읽는 언어를 한국어로 설정하면, sam의 메시지 아래에 ✦ 표시와 함께 "오늘 밤 랭크 할 사람?"이 나타납니다. lucia의 메시지 아래에는 "나 할래, 9시에?"가 나옵니다. jiwoo의 메시지는 이미 한국어이므로 Subline은 아무것도 덧붙이지 않습니다.

번역에는 AI 모델을 사용하기 때문에 게임 은어, 줄임말, 여러 언어가 섞인 문장도 직역이 아니라 자연스러운 한국어로 읽힙니다.

어디에서 쓸 수 있나요

  • Mac과 Windows의 디스코드 앱. Subline 앱이 지금 쓰는 디스코드에 Subline을 추가합니다. 창도 계정도 알림도 그대로입니다.
  • Chrome에서 쓰는 디스코드. Chrome 웹 스토어에서 Subline을 추가한 뒤 discord.com을 엽니다. Linux에서는 이 방법으로 쓰면 됩니다.

시작하는 방법

  1. 메인 페이지에서 Subline을 내려받거나 Chrome에 추가합니다.
  2. 디스코드를 열고, 설정 사이드바에서 Subline 항목을 찾아 Settings를 엽니다.
  3. 읽을 언어를 고릅니다. Subline은 82개 언어를 지원하므로, 서버에서 자주 마주치는 언어는 대부분 포함됩니다.

이제 서버의 채널을 열면 다른 언어로 된 메시지 아래에 번역이 표시됩니다. 개인 메시지는 메시지의 🌐 버튼으로 켜기 전에는 번역되지 않습니다.

자주 묻는 질문

  • 다른 사람도 번역을 볼 수 있나요? 아니요. 내 화면에서만 보이고, 서버의 누구도 알아채지 못합니다.
  • 서버에서 뭔가 설치해야 하나요? 아니요. 이미 들어가 있는 어떤 서버에서도 작동합니다.
  • 안전한가요? 보안 페이지에서 무엇이 전송되고 어디로 가는지 설명합니다.
