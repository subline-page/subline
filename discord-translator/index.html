Discord translator: four ways to read a chat in another language

Updated 2026-11-17

Copy and paste, a bot, a per-message button or a reader that works by itself. What each Discord translator is good at, and which one fits following a live chat.

What you are really asking for

"Discord translator" can mean four different things, and they solve four different problems. Before you pick one, decide which problem you have.

Maybe you are reading. A server moves fast in Portuguese or Korean, and you want to follow along in your own language. Maybe you are writing, and you want your reply to arrive in their language. Maybe you run the server and want every member to understand each other. Or maybe you only need to decode one odd message today.

This page is about the first problem: reading a live chat you cannot read. If that is yours, here are the four ways people do it, and where each one runs out.

Way 1: copy, paste, switch tabs

You select the message, paste it into a translation website, read the result, and go back to Discord. It works anywhere and needs nothing installed.

It also breaks the moment the chat moves. Ten messages in a minute means ten trips between tabs, and by the time you understand line three, the talk has moved on to line nine. Short slang suffers too, because a single line pasted alone has lost the messages around it. A "same" or a "lol no" can mean almost anything without context.

Good for: one message, once in a while.

Way 2: a bot that posts translations

A bot is an app that a server owner or an admin adds to the server. Members trigger it with a command or a reaction, and it posts the translation into the channel as a new message.

The catch is who has to say yes. If you are a guest in someone else's server, you cannot add a bot, and an admin may not want one. When a bot does run, its copies go to everyone, so a channel of mixed languages can double in length. That is fine for a server that chose it on purpose. It is no help to a single reader.

Good for: a server whose admins want shared translation in the open.

Way 3: a button on each message

Some tools add a small button to every message. You press it, and a translation shows up for that one line.

This is a real step up from copy and paste, because the translation appears in place and nothing is posted for others. But you still decide, message by message, whether to press. In a channel with several languages, you press all day. And you have to know a line is worth translating before you see what it says, which is the part you cannot know.

Good for: a quiet server where you only need the odd line.

Way 4: a reader that works by itself

The last kind translates every message you read, without a click, and shows the result under the original. Only you see it. The chat stays as it was.

This is what Subline does. If you read English, a Spanish line gets an English line beneath it, marked with ✦. Messages already in your language get no line. Laughter, emoji and links stay as they are, so a busy channel does not fill up with noise.

Good for: following a live chat, in any server, as a guest.

Where Subline runs

It runs in the Discord app on Mac and Windows, and in Discord on discord.com through the Chrome add-on. Linux users use the Chrome add-on. It supports 82 reading languages.

Server channels are translated by themselves. Direct messages and group DMs stay off until you turn one on with the 🌐 button, so nothing private is sent without you choosing it.

What it does not do

  • It does not translate what you send. You write in your own language, as you always did.
  • It does not translate voice chat.
  • It does not work on phones.
  • There is no Firefox, Edge or Opera version yet.

One more thing to know before you install. Subline is built on Vencord, a client mod, and Discord's terms do not allow client mods. The safety page explains what that means and what Subline does and does not touch. Subline is not made by or affiliated with Discord.

How to choose

  • You read one message now and then: copy and paste is enough.
  • Your admins want shared translation in the open: a bot fits.
  • You press a button a few times a day: a per-message tool is fine.
  • You want to follow a moving chat in a server you do not run: use a reader that works by itself.
