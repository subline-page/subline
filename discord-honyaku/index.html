Discord 翻訳: メッセージを自動で自分の言語に、Bot なしで

更新日 2026-11-20

Discord を自動翻訳する方法。コピペ、Bot、Vencord、Subline を比較。Subline は各メッセージの真下に、あなただけに見える翻訳を表示します。

知らない言語のサーバーに入ったとき

ゲームや勉強会、海外のコミュニティのサーバーに入ると、チャットの半分が英語やスペイン語、ポルトガル語、トルコ語で流れていきます。会話は速く、読んでいるうちに置いていかれます。Discord の翻訳方法を探すと、仕組みのまったく違う方法がいくつも見つかります。何かを入れる前に、それぞれの違いを知っておくと安心です。

Discord を翻訳する4つの方法

  1. コピーして貼り付ける。 メッセージをコピーして翻訳サイトに貼り、読んでから戻ります。一文だけなら十分ですが、数秒ごとに流れるチャンネルでは追いつけません。
  2. 翻訳 Bot。 サーバーの管理者が Bot を追加します。国旗のリアクションやコマンドで、Bot が翻訳したコピーをチャンネルに投稿します。管理者が入れたサーバーでしか使えず、全員のチャットに翻訳が増えていきます。
  3. Vencord の Translate 機能。 Vencord は Discord のオープンソースの改造ツールです。Translate 機能は、メッセージをクリックすると Google 翻訳で訳してくれます。便利ですが手動で、メッセージごとに1回クリックが必要です。
  4. Subline。 メッセージが届いた時点で自動的に翻訳し、その真下にあなたの言語で表示します。クリックも Bot も不要で、見えるのはあなただけです。

実際のチャットではこう見える

国際的なサーバーでは、たとえばこんな流れになります。

  • sam: anyone up for ranked tonight?
  • lucia: yo me apunto, a las 9?
  • mika: 今夜なら大丈夫です

読む言語を日本語にしておくと、sam のメッセージの下には ✦ 付きの行で「今夜ランクマ行ける人いる？」と表示されます。lucia のメッセージの下には「いいね、参加するよ。9時で？」と出ます。mika のメッセージはすでに日本語なので、Subline は何も足しません。

翻訳には AI モデルを使っているので、ゲームのスラングや略語、複数の言語が混ざった文も、直訳ではなく自然な日本語で読めます。

使えるところ

  • Mac と Windows の Discord アプリ。 Subline のアプリが、いま使っている Discord に Subline を追加します。ウィンドウもアカウントも通知も、これまでと同じです。
  • Chrome 上の Discord。 Chrome Web Store から Subline を追加して、discord.com を開きます。Linux ではこの方法で使えます。

はじめかた

  1. トップページから Subline をダウンロードするか、Chrome に追加します。
  2. Discord を開き、設定のサイドバーにある Subline の項目から Settings を開きます。
  3. 読みたい言語を選びます。Subline は82の言語に対応しています。

これで、開いたサーバーのチャンネルでは、他の言語のメッセージの下に翻訳が表示されます。ダイレクトメッセージは、メッセージの 🌐 ボタンで有効にするまで翻訳されません。

よくある質問

  • ほかの人にも翻訳は見えますか？ いいえ。見えるのはあなたの画面だけで、サーバーの誰にも気づかれません。
  • サーバーに何か入れてもらう必要はありますか？ いいえ。すでに参加しているどのサーバーでも使えます。
  • 安全ですか？ 安全性のページで、何が送られ、どこへ行くのかを説明しています。
  • 料金はいくらですか？ 最初の翻訳から7日間は AI 翻訳が含まれます。その後は月額 US$1.99、または年額 US$19.99 です。

Subline: すべてのメッセージを、すぐ自分の言語で
